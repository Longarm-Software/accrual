# Brand

The logo is **Ring**, chosen on 19 November 2026 from the five marks in round 3: a lowercase "a"
whose bowl is the Available gauge from the category screen.

| Mark | Mark, one colour | App icon | App icon, light |
|---|---|---|---|
| <img src="accrual-mark.svg" width="120" alt="Accrual mark in mint to blue"> | <img src="accrual-mark-mono.svg" width="120" alt="Accrual mark in one colour"> | <img src="accrual-app-icon.svg" width="120" alt="Accrual app icon, dark"> | <img src="accrual-app-icon-light.svg" width="120" alt="Accrual app icon, light"> |

| File | Use |
|---|---|
| `accrual-mark.svg` | The mark in Aurora's mint to blue, for dark backgrounds |
| `accrual-mark-mono.svg` | The mark in one colour. It takes the colour of the text around it |
| `accrual-app-icon.svg` | App icon, dark. 1024 units square with no rounded corners; the system rounds them |
| `accrual-app-icon-light.svg` | App icon on the gradient, as an alternative |

These are generated by `node design/src/brand.mjs`. Edit the mark there, not in the files.

## Not done

- **No search for similar logos or trademarks has been made**, and the name itself is unchecked
  (see [`docs/business.md`](../../docs/business.md)). Do both before a store listing.
- **No wordmark.** "Accrual" has only been set in Bricolage Grotesque as a stand-in.
- **The mark is as drawn in the exploration.** Its proportions have not been refined, and it has
  not been tested as an Android adaptive icon, a monochrome themed icon, or a notification icon.
- **Colours:** mint `#62EFC2`, blue `#5CCBF4`, dark `#07090C`, ink on the gradient `#062019`.
